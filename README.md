# PathPoint
This is a revolutionary mobile app that can help commuters

PathPoint is a mobile application that helps users find the most efficient commuting routes and estimate travel fares.  
Users can set their trip by pinpointing Point A (origin) and Point B (destination) on a map.  
The app then recommends the optimal route using public transportation options and calculates the estimated fare.

---

## Features

- **Smart Route Recommendation** – Get the most time-efficient and cost-effective public transport routes.
- **Fare Calculation** – View estimated fares for your selected trip.
- **Multiple Transit Modes** – Support for buses, trains, jeepneys, and other local transportation options.
- **User-Friendly Interface** – Simple and clean design for quick navigation.

---

## Tech Stack

- **Frontend:** Flutter
- **Backend:** Firebase
- **Database:** Firebase
- **Mapping & Routing:** Google Maps API
- **Fare Calculation:** Custom fare computation logic
